# Regloft AI — AI-Powered Compliance SaaS

**Full-Stack SaaS Development | AI Integration | Cloud Applications**

**Live Application:** https://regloftai.com/

## Overview

Regloft is an AI-assisted compliance workspace developed for UK small and medium-sized businesses.

The project explores how artificial intelligence and modern web technologies can help businesses draft policies, organise supporting documentation, monitor compliance readiness and manage practical follow-up actions.

This is a full-stack SaaS development project demonstrating AI API integration, user authentication, database-backed workflows and subscription-based application architecture.

## Core Features

- **AI Policy Generation:** Draft GDPR, cybersecurity, AI usage, HR and supplier-risk policies.
- **Company Profiles:** Use business details to personalise generated documents.
- **Document Library:** Organise, manage and export compliance documents as PDFs.
- **Readiness Dashboard:** Display completed items, missing documents and actions requiring attention.
- **Audit Readiness:** Prepare reports and structured compliance packs.
- **Action Plans:** Organise tasks, priorities, evidence requirements and review dates.
- **User Authentication:** Support accounts and access to personalised workspaces.
- **Subscription Billing:** Integrate Stripe for subscription and billing workflows.

## Application Workflow

1. A user creates an account and enters their company information.
2. The user selects a compliance document or policy type.
3. The application processes the business context and requests an AI-generated draft.
4. The generated content is presented for review.
5. Documents can be organised and exported.
6. The dashboard helps identify outstanding actions and review requirements.
